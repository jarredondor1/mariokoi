# Procedencia visual

- Las cuatro ediciones de koi derivan exclusivamente de `Koi_Fish.stl`, proporcionado por el usuario. La geometría se optimizó mediante [`tools/prepare-stl-koi.py`](tools/prepare-stl-koi.py) y cada edición recibió una pintura de vértices distinta con [`tools/build-ornamental-school.py`](tools/build-ornamental-school.py) en Blender.
- El anterior `koi-kintsugi` y el modelo de `koi.stl` ya no se cargan en la página.
- [Sketchfab: modelos etiquetados koi](https://sketchfab.com/tags/koi) y el modelo [CC0 Carp de ffish.asia](https://sketchfab.com/3d-models/cc0-carp-cyprinus-carpio-animation-c79dcd2ce7074bac9ce3cb0c11eccb6b) se consultaron como referencias visuales; sus archivos no se descargaron ni se incluyeron.
- [Kintsugi Koi — The Clockwork Companion](https://www.meshy.ai/es/posts/kintsugi-koi-the-clockwork-companion-01a02352-36a4-72a9-94e2-9ad4575539cd) se consultó como referencia de dirección artística. La descarga solicitó iniciar sesión; construimos una interpretación propia y ese archivo no está incluido en la web.

## Tattoo preview studies
- `public/models/preview/*-anatomical.mesh`: adapted from the MakeHuman hm08 base mesh and adult female/male macro targets. Source: https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data . Asset license: CC0 1.0 Universal (https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md). Original asset data and license are retained in `assets/mannequins/`. `scripts/create-mannequins.mjs` blends adult macro targets, excludes rig/clothing helpers, normalizes height, applies one Catmull–Clark subdivision pass, and packs indexed position/normal data. No MakeHuman application source code is bundled.
- `public/designs/{koi,lotus,serpent,moth}.svg`: original temporary vector studies created for this preview; **not works attributed to Mario Koi**. Replace these examples with the artist's approved transparent artwork before presenting them as his portfolio.
